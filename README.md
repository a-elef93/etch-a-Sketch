Etch-a-Sketch

A browser-based Etch-a-Sketch project built as part of The Odin Project – Foundations curriculum.

Features

* 16×16 grid generated dynamically with JavaScript
* Hover effect to draw over the grid
* Button to create a new grid
* Custom grid size up to 100×100
* Grid squares automatically resize to fit the container
* Input validation for grid size
* Random RGB color squares on hover

Built With

* HTML
* CSS
* JavaScript
* DOM Manipulation
* Event Listeners

What I Practiced

* Creating DOM elements with JavaScript
* Using loops to generate elements
* Handling mouse and click events
* Working with user input
* Dynamically changing element styles and sizes
* Organizing code into reusable functions
